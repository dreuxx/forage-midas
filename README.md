# JPMorgan Chase Forage - Midas Project

This repository contains my solution for the **JPMorgan Chase Software Engineering Virtual Experience Program** on Forage.  
The project simulates a financial transaction platform called **Midas** where users can send money and query their balances.

## 🛠️ Technologies Used
- Java 17
- Spring Boot
- Apache Kafka
- H2 In-Memory Database
- Maven

## 📚 Completed Tasks
- Task 1: Set up the base Spring Boot application and Kafka listener
- Task 2: Process transactions and update user balances
- Task 3: Integrate with the Incentive API
- Task 4: Process and store transaction records
- Task 5: Create a REST API to expose user balances

## 🚀 How to Run
1. Clone the repository
2. Start the Incentive API (provided by JPMorgan)
3. Start the Spring Boot application (`Midas Core`) on port 33400
4. Test the `/balance` endpoint

## 🎯 Key Learnings
- Spring Boot microservices
- Kafka messaging system
- Transactional data processing
- RESTful API development
- Clean architecture decisions
